# Григорівське — вулиця, а не шосе

Односторінковий сайт громадської ініціативи мешканців Холодної гори (Харків) за безпечне перехрестя Григорівського шосе та вулиці Львівської.

Стек: Vite, звичайні HTML і CSS, близько 1,5 КБ JavaScript. Без фреймворків, трекерів і зовнішніх запитів.

## Що де лежить

| Шлях | Що це |
| --- | --- |
| `site.config.js` | Налаштування: `SIGN_URL`, `CONTACT_URL`, `SITE_URL`, `UPDATED` |
| `index.html` | Уся сторінка й тексти |
| `src/style.css` | Стилі за брендбуком «Харків для Людей»: Raleway, палітра, світла й темна теми |
| `brand/` | Лого й вотермарк з брендбука (`AI_content/projects/2026-11_brandbook`). Копії для сайту лежать у `public/brand/` і `public/favicon.svg` |
| `src/main.js` | Закріплена кнопка на мобільних і кнопка «Поділитися посиланням» |
| `photos/` | Оригінали фото. Скрипт їх не змінює. До git не потрапляють |
| `scripts/optimize-images.mjs` | Стискає фото з `photos/` у `public/img/` |
| `public/img/` | Стиснені копії (WebP + JPEG, кілька ширин) і `og.jpg` |
| `images.manifest.json` | Розміри копій. Генерується скриптом |
| `vite.config.js` | `base: './'` і плагін, що підставляє налаштування й розмітку фото |

## Команди

Потрібен Node.js 20 або новіший.

```bash
npm install        # один раз
npm run images     # стиснути фото з ./photos (після додавання чи заміни фото)
npm run dev        # локальний сервер для розробки
npm run build      # зібрати сайт у ./dist
npm run preview    # переглянути зібраний сайт локально
```

Після зміни `site.config.js` перезапустіть `npm run dev`.

## Налаштування (`site.config.js`)

- `SIGN_URL` — посилання на петицію чи форму підписів. Поки порожнє, кнопки «Підписати» ведуть до розділу «Як допомогти», а там написано «Збір підписів скоро розпочнеться».
- `CONTACT_URL` — `https://t.me/…`, `mailto:…` або `tel:…`. Поки порожнє, рядок контакту не показується.
- `SITE_URL` — повна адреса сайту зі слешем у кінці, наприклад `https://username.github.io/repo-name/`. Без неї картинка не з'явиться в прев'ю посилання в Telegram, Viber і Facebook.
- `UPDATED` — дата оновлення в підвалі (`YYYY-MM-DD`). Порожнє значення означає дату збирання.

## Фото

Покладіть файл у `photos/` з назвою, яку очікує скрипт (список — у `IMAGES` у `scripts/optimize-images.mjs`), і запустіть `npm run images`. Якщо файлу немає, скрипт створює сіру заглушку з правильними пропорціями і пише про це в консолі. Збірка теж попереджає про заглушки.

Стиснені копії не містять EXIF, тож GPS-координати й дані телефона не публікуються.

На `og.jpg` (прев'ю посилання в месенджерах) скрипт ставить вотермарк `brand/watermark.png` за брендбуком: 15% короткої сторони, правий нижній кут, відступ 2,5%, непрозорість 0.85.

## Брендбук

Оформлення відповідає брендбуку «Харків для Людей» v1.2:
- шрифт Raleway (500 текст, 700–800 заголовки) з рівними цифрами;
- заголовки «Чорнилом», кнопки «Парком», фон розділу «Що ми пропонуємо» — «Повітря»;
- у порівнянні «Зараз» на «Цеглі», «Пропозиція» на «Парку», як «було / стало»;
- «Сонце» лише раз, на головній думці розділу «Проблема»;
- «Як допомогти» оформлено як лінію-маршрут із зупинками;
- на темному тлі показується лого «У колі», бо синій напис основного лого там зникає.

## Публікація на GitHub Pages

1. Створіть репозиторій на GitHub і завантажте код:
   ```bash
   git init
   git add .
   git commit -m "Перша версія сайту"
   git branch -M main
   git remote add origin git@github.com:USERNAME/REPO.git
   git push -u origin main
   ```
   `public/img/` і `images.manifest.json` мають бути в коміті: на GitHub оригіналів фото немає.
2. У репозиторії відкрийте **Settings → Pages** і в **Source** виберіть **GitHub Actions**.
3. Workflow `.github/workflows/deploy.yml` збере й опублікує сайт після кожного push у `master`. Адреса: `https://USERNAME.github.io/REPO/`.
4. Впишіть цю адресу в `SITE_URL`, закомітьте й запуште ще раз.

Перевірити, як розгортається посилання: [opengraph.xyz](https://www.opengraph.xyz/) або бот `@WebpageBot` у Telegram (він також оновлює кеш прев'ю).

Ще можна завантажити вміст `dist/` на будь-який статичний хостинг: через `base: './'` сайт працює з будь-якої підпапки.
